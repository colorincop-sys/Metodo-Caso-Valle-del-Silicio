# Metodo-Caso-Valle-del-Silicio
 Implementación en lenguaje C del algoritmo shuffle utilizando Fisher-Yates, incluyendo comentarios y control de errores.
 
 El caso plantea la necesidad de diseñar un algoritmo eficiente para mezclar aleatoriamente una lista de canciones (shuffle), optimizando procesos en la empresa. El objetivo es reducir tiempos, mejorar la gestión de información y aumentar la calidad del sistema. 
Desde la teoría, esto corresponde a la fase de análisis y diseño del programa, donde se identifican requisitos y se define la solución algorítmica antes de implementarla. 

## Problema principal
-	Baja eficiencia en algoritmos actuales
-	Necesidad de mayor aleatoriedad
-	Optimización de recursos

  
## Propuesta de solución

-	Diseñar un algoritmo de mezcla aleatoria bien estructurado
-	Usar pseudocódigo, modularidad y estructuras de control
-	Aplicar buenas prácticas de programación
